حويشة — تطبيق ادخار الهاتف
============================

تشغيله فورًا:
- افتح index.html في Chrome أو Safari حديث. التطبيق عبارة عن HTML واحد يحتوي CSS وJavaScript داخله.
- أنشئ حسابك باسم مستخدم وكلمة مرور لا تقل عن 8 أحرف.
- استخدم (دخل جديد) لتسجيل مرتبات يومية/أسبوعية أو شغل خارج العمل.
- استخدم (أحوش فلوس) لتسجيل ادخار من المرتب أو الشغل الخارجي.
- استخدم (أسحب فلوس) لتسجيل السحب، ثم (أرجّع سحب) لاختيار السحب الذي سددته جزئيًا أو كليًا.
- ستظهر الحسابات والتقارير تلقائيًا.

تثبيت حقيقي كأيقونة تطبيق تعمل أوفلاين:
1) ارفع ملفات مجلد Hawisha-Mobile جميعها إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Netlify).
2) افتح رابط الموقع عبر Chrome على Android، ثم القائمة > Install app / إضافة للشاشة الرئيسية.
3) على iPhone افتح الرابط بـ Safari، ثم مشاركة > Add to Home Screen / إضافة إلى الشاشة الرئيسية.
4) افتح التطبيق مرة واحدة أونلاين بعد التثبيت، وسيعمل أوفلاين عبر Service Worker.

مهم جدًا:
- البيانات محفوظة داخل متصفح/نسخة التطبيق على الجهاز وليس على خادم أو حساب إلكتروني.
- عملية إنشاء الحساب تُشفّر البيانات محليًا بـ PBKDF2 + AES-GCM.
- اعمل نسخة احتياطية مشفرة من الإعدادات، خصوصًا قبل مسح بيانات المتصفح أو تغيير الهاتف.
- إذا نسيت كلمة المرور لا يوجد استرجاع إلكتروني؛ النسخة المشفرة تحتاج كلمة المرور الأصلية.
- البصمة ليست مفعلة في هذه النسخة؛ تتطلب WebAuthn أو ربطًا آمنًا بالنظام ولا يصح عمل زر شكلي.
- تغيير العملة يغير الرمز ولا يحول المبالغ بأسعار الصرف.
- ملف CSV غير مشفر، لذلك تعامل معه كمستند مالي خاص.

إصلاحات النسخة 1.1 — 08/10/2026:
- تم حل مشكلة ظهور تنبيه «اسم المستخدم لازم يكون 3 حروف على الأقل» رغم كتابة الاسم؛ السبب فقدان name من حقول إنشاء الحساب.
- كلمة المرور وتأكيدها الآن يصلان بصورة صحيحة لمنطق إنشاء الحساب.
- منع تراكم التنبيهات المتكررة ومحاولة الإرسال المتزامنة.
- خانة «أحوش من الدخل ده» أصبحت اختيارية فعلًا.
- تحديث التخزين المؤقت للتطبيق على الاستضافة لاستلام الإصلاحات الجديدة بسهولة.

لو مثبت إصدار قديم من التطبيق على نفس الرابط، أعد رفع الملفات وانتظر تفعيل النسخة الجديدة ثم أغلق التطبيق وأعد فتحه. لا تمسح بيانات الموقع لو سجّلت مبالغ قبل أخذ نسخة احتياطية.
